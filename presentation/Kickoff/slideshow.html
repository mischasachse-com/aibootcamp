06

Security Baseline

Keyless by default — no API keys, ever

How auth works

>

All code uses DefaultAzureCredential — tokens from az login

>

Access is pure Azure RBAC — who you are decides what you can call

>

No API keys, no connection strings — not in code, not in .env, not in examples

>

.env holds endpoints/identifiers only — gitignored, mode 600

CI gate: the pipeline runs a secret-pattern scan over the repo — it never deploys, it only verifies.

Why it matters

"If a key can be copied, it will be."

Keyless auth is the production standard on Azure — and it is what this bootcamp expects you to default to at work.

08

Safety Protocol

Rules of engagement

Untrusted output

>

Everything the model emits is untrusted until a human signs off

>

AI-drafted IaC is reviewed, never auto-deployed

>

A hardened prompt is a speed bump — not a security boundary

Gated writes

>

Write tools are off by default — simulated until the trainer enables them

>

Every real write needs interactive human approval + a scope check

>

All tool calls are written to an audit log

Isolation & teardown

>

Work only inside your own squadron RG

>

scripts/reset-data.sh resets lab data between sessions — infra untouched

>

Teardown is trainer-gated: milestones verified first, then a double-confirmed script

Questions are always welcome — experiment freely, safely.
