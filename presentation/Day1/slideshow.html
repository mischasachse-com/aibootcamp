05

Pre-flight Configuration

Key choices in a RAG pipeline

Chunk strategy

~1200 chars + 150 overlap

Structure-aware: split on ## headings. Too small loses context, too large adds noise.

Embedding model

3072 dimensions

text-embedding-3-large. The indexer measures the dimension and fails fast on mismatch — no silent schema drift.

Search strategy

Hybrid + semantic

Keyword + vector beats pure vector on technical docs. Free-plan ranker exhausted? semantic_fallbacks.log + non-semantic fallback.

Every step is Python code you write in the lab — understand it, don't just run it.

Security Lens

The manuals contain a secret
